Core Role Responsibilities

The Moderator Role

The Moderator is the public-facing guide for the block: welcoming attendees, introducing each item, facilitating Q&A, and protecting the published schedule.

  • Use the scripts: Give the block welcome and the detailed session introduction, including the timing structure and how audience questions will work.
  • Own the transitions: Return on camera for Q&A, close on time, thank presenters, and never begin the next item before its published start time.
  • Keep the audience oriented: Announce lunch, day closings, and any unexpected schedule adjustments.
  • Coordinate quietly: Stay in contact with Tech Support if a presenter is late or a technical issue threatens the schedule.

The Tech Support Role

Tech Support runs the backstage: Zoom controls, presenter readiness, recording, permissions, Q&A support, and the countdown timer.

  • T-10 readiness: Confirm the next presenter is in the room, message them directly in Zoom chat, and grant Co-host status. This is not a scheduled tech check.
  • Own Zoom controls: Waiting room, mute settings, Q&A, live transcription, presenter permissions, and session-specific Chat settings.
  • Run the clock: Use 20/5/5 for 30-minute sessions and 45/10/5 for 60-minute sessions. Keep the timer visible and use the chime at time.
  • Keep the timer feed visible: If the timer is being displayed through the Tech Support video/virtual-background feed, keep that video feed on for the presentation so the timer remains visible. Cover the webcam if needed while leaving the virtual background active.
  • Manage recording: Start/stop recording as directed. Use Speaker View for monitoring and confirm the intended active-speaker/shared-screen cloud-recording layout.
  • Support live Q&A: Unmute raised-hand participants and re-mute them after the exchange.
  • Reset between sessions: Return outgoing non-committee presenters to Participant, preserve planning committee Co-host status, and restore the correct Chat setting for the next item.

Planning Committee Co-host Rule

Planning committee members are Joshua Been, Eric Ames, Millicent (Millie) Weber, Mike Thompson, Ezra Choe, and Jenna Palensky. Ensure committee members present are Co-hosts and do not revoke their Co-host status after a committee member presents or facilitates.

Host Rule

Millie owns the scheduled Zoom meeting. On Thursday she starts each block and remains Host/Tech Support. On Friday Millie starts each block, then transfers Host to Joshua Been, who serves as Tech Support for the day.
