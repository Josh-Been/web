Core Role Responsibilities

The Moderator Role

The Moderator is the public-facing guide for the block: welcoming attendees, introducing each event, facilitating Q&A, and protecting the published schedule.

  • Use the spoken scripts: Deliver the brief housekeeping, event introductions, Q&A prompts, hard-stop language when needed, and block/symposium closings.
  • Protect the clock: The event timer begins at the published start time and includes the introduction. If the final timer chimes while a presenter is still speaking, use the hard-stop script.
  • Own transitions: Share the agenda slide during each unrecorded five-minute transition and never begin the next event early.
  • Handle contingencies: Work with Tech Support on missing presenters and deliver the prepared cancellation announcement when necessary.

The Tech Support Role

Tech Support runs the backstage: Zoom controls, presenter readiness, permissions, recording, Q&A support, and the countdown timer.

  • Run T-10 readiness: Locate each presenter, message each person individually, and grant/confirm Co-host status as specified.
  • Manage permissions: Committee presenters retain Co-host status. At the end of each event, mute outgoing presenters if needed and return noncommittee presenters to Participant.
  • Manage recording: Before every individual event, set the Host’s Zoom view to Speaker View, start cloud recording, announce “The recording has started,” and immediately start the event timer. The cloud recording mirrors the Host’s view: in Speaker View, attendee cameras are not included unless an attendee is permitted to unmute and speaks. Stop recording after the Moderator’s event-specific closing.
  • Support Q&A: Monitor Q&A and Raise Hand. For a live question, use Ask to Unmute, then mute if needed and lower the hand afterward.
  • Protect transitions: Transitions are not recorded. Make any required Chat-setting changes during the transition, not during a T-10 readiness check.
