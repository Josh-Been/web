How to use the builder

Lock the project setup, add three agents, then work from top to bottom in the sidebar. Click an agent to assign its workflow name. Click an item on an agent card to remove it. Drag a Constraint tile anywhere onto the workflow; then use the Workflow Constraints badge to enter its value and priority.

Example workflow

Manager defines and prioritizes candidate constraints → Researcher curates standardized job evidence → Analyst produces the standardized Search Strategy.
